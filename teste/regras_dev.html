Desenvolvimento (Dev)

  • Tamanho da Equipe: As equipes podem ter 5 programadores.
  • Desafio: Criar uma solução web ou mobile para um problema real da indústria. O tema é surpresa.
  • Duração: Formato Hackathon de 8 horas consecutivas.
  • Equipamentos: Senai ira fornecer os notebooks com as coisas necessarias. A internet será fornecida via cabo (LAN).
  • Plágio: O uso de bibliotecas de código aberto é permitido, mas copiar projetos prontos resulta em desclassificação.
